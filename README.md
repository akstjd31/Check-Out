# 주요 구현 기능

## 1️⃣ State 패턴 기반 씬 전환 시스템

게임의 흐름을 상태 단위로 분리하여  
씬 전환 로직을 구조화했습니다.

### 기존 문제
- 씬 이동 로직이 분산됨
- 유지보수 어려움 발생

### 해결
State 패턴 기반으로

- Init
- Main
- Hub
- Session
- Dead

상태를 분리하여 전환 로직을 관리했습니다.

---

## 2️⃣ 위치 기반 이벤트 시스템 설계

플레이어가 특정 위치에 진입하거나  
특정 조건을 만족했을 때 이벤트가 실행되는 구조를 구현했습니다.

각 이벤트는 Trigger 기반으로 동작하며  
게임 진행 흐름에 맞춰 순차적으로 활성화됩니다.

### 이벤트 예시
- 특정 구역 진입 시 사운드 재생
- 특정 오브젝트 상호작용 활성화
- 대사 출력 이벤트
- 목표 아이템 획득 이벤트
- 탈출 조건 활성화

### 개선 내용
기존에는 이벤트 로직이 개별 오브젝트에 분산될 가능성이 있었지만

- 이벤트 조건
- 실행 로직
- 진행 상태

를 분리하여 관리할 수 있도록 설계했습니다.

이를 통해 새로운 이벤트 추가 시  
기존 코드를 크게 수정하지 않고 확장이 가능하도록 구현했습니다.

---

## 3️⃣ Generic Save / Load 시스템

게임 진행 데이터를 저장하고  
다시 불러올 수 있는 구조를 구현했습니다.

### 저장 데이터
- 플레이어 진행 상태
- 획득 아이템 정보
- 이벤트 진행 상태

### 개선 내용
제네릭 구조를 활용하여  
다양한 데이터 타입 저장이 가능하도록 설계했습니다.

# 🛠 기술적 고민

기획 파트가 직접 이벤트를 테스트하는 과정에서  
높은 초기 세팅 비용이 발생했고 테스트 접근성이 낮았습니다.

이를 해결하기 위해

- 이벤트 흐름 사전 검증
- 프로토타이핑 기반 커뮤니케이션 개선
- 테스트 구조 단순화

방식으로 협업 프로세스를 개선했습니다.
